# Life Game (128x128)

Conway's Game of Life on a 128x128 toroidal grid. Pure HTML/CSS/JS, no build step.

## Usage

Open `index.html` in a browser, or serve the folder with any static server.

- **Start** / **Stop**: run or pause the simulation
- **Step**: advance one generation
- **Random**: randomize the grid
- **Clear**: kill all cells
- Click a cell to toggle it alive/dead
- Speed slider controls generations per second

## Deploying to GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repo settings, go to **Pages** and set the source to the `main` branch, root folder (`/`).
3. The site will be published at `https://<username>.github.io/<repo>/`.
